Conductivity improvement using overprint

Via hole on paper using laser cutter

Instant inkjet circuit – using silver nanoparticle ink to print conductive pattern – has been known as a method to rapidly fabricate electronic circuit on flexible substrates. Although it can be used to make many types of circuit, the effect of resistance still remains if we fabricate conductive pattern like antenna for Wireless Power Transmission. In order to improve conductivity of printed pattern, we tweaked the inkjet printer driver to control the printing process so that we can overprint a pattern time to time in a same sheet of paper. By overprinting, the sheet resistance has decreased from 0.19 ohm per square (Ω/□) to 0.043Ω/□.  
Currently, we are also working on prototyping of multi-layered circuit on paper. Starting with double sided circuit, we develop a process to fabricate via hole to connect 2 silver printed circuits on both sides of a paper. This via hole can be made by laser cutter or some special designed needles. In the future, we will implement a method to fabricate multi-layered circuit using silver nanoparticle ink and inkjet printer.
