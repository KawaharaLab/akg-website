What if we install an algorithm that works as a counter to human false cognitive biases, by using tools that learn the current biases with deep learning and similar technologies? This project questions how we should design “the fair society” using technologies, and whether this is the right or wrong direction to go. As a speculative draft, I propose an “Alt Bias Gun” that reflects the “Black Lives Matter” activist movement.
