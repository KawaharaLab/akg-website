We proposed smartphone sensing system using interactive application called Cisco Spark. This system assumes the use of smartphones in outside fields where sensing period is long. In our proposed system, the smartphones are turned off when they are not used in order to save power consumption. Responding to the users’ command through Cisco Spark, smartphones located in remote places are woken up via microwave power transfer, which then sense and send back data to the system.

Takashi Ikeuchi, Masaru Takagi, Yoshihiro Kawahara
