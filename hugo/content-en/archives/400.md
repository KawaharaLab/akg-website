Usually, it takes very long time to realize an antenna through simulations. In this research, we propose a method to implement antennas rapidly with a process of trial and error by means of inkjet printing technology, a way to implement antennas much faster than using milling machines and print boards.  
Running a simulation is the main way to get the information about an antenna such as band width and characteristic impedance. However, simulation is very time-consuming especially when using a genetic algorithm, which needs to calculate repeatedly. Therefore in our research, we suggest using inkjet technology to realize each antenna and use the measurement results, instead of complex calculations. If the shape of antenna is too complicated, it can be expected that this method can get much quicker results than the calculation. Adopting an easier design model and trying more samples becomes possible if the rapid prototyping of antenna is realized.
