Although we can see the bottom eye is closed when the general multilevel ASK is adopted, the every eye opens when the proposed method is applied. This result indicates that the proposed method improves the communication performance on the sysytem.

By conducting data transmission with the same hardware as the power transmission in a wireless power transfer (WPT) system, it is expected that communication for the system control or communication among battery-less devices can be realized.  
The transfer characteristic via resonance coupling is approximated as a kind of narrowband band-pass filters, which is different from the case of propagating radio waves through the air using antenna. Therefore, it is difficult to improve the bit rate by increasing the modulation speed (baud rate). To deal with this problem, we made an approach which increases bit per symbol by using multilevel modulation. In this research, we focused on “multilevel ASK” and proposed a signal generation method by which the transferred signal is made up of the sum of the fluctuating amplitude for data transmission and the constant amplitude for powering. According to the experimental results, bit rate on a multihop WPT system is improved by this method compared to general OOK (On-Off Keying).
