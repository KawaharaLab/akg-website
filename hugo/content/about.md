{{< about-section id="lab" title="研究の進め方" >}}
### 材料からAIまで、一緒に設計する

AIの処理が重いなら、モデルだけでなくセンサを変える。制御が難しいなら、身体の形や柔らかさを変えてみる。材料、構造、デバイス、回路、通信、計算、AIを横断し、どこで何を解くのがよいかを考えます。

### できるだけ、計算しない

柔らかい指が物体の形に沿って変形するように、形や材料、環境との相互作用に仕事の一部を任せます。変化したときだけ情報を出すセンサや、布そのものを回路にする方法も、問題を簡単にするための設計です。

### 実際につくり、実環境で試す

回路を刷る。布を編む。ロボットを動かす。モデルを学習させる。実環境で試し、うまくいかなければ設計をやり直します。論文で終わらず、現実世界で使えるところまで持っていきます。

**誰もが、自分でつくれる。直せる。選べる。**

少ない電力で動き、身近な方法でつくれ、自分で直し、変えられる技術を、人の手元に届けることを目指しています。

現在の研究は [Research](/research/) に、企業・機構・起業を通じた社会との接点は [Engagement](/engagement/) にまとめています。

{{< about-section id="history" title="これまで" >}}
JST ERATO 川原万有情報網プロジェクト（2015〜2022年）では、ファブリケーション・センシング・アクチュエーション・エネルギーの四つの軸で、人工物があらゆる環境に溶け込む世界を目指しました。

この取り組みとその後の研究には、市販プリンタで回路を印刷する [Instant Inkjet Circuits](/archives/1)、印刷した平面が熱で立体になる [Inkjet 4D Print](/archives/4815)、壊れやすいものを潰さずにつかむ [Delicate Jamming Grasp](/archives/5054)、環境音による[屋内位置測位](/archives/4966)、部屋のどこでも機器に給電するルームスケール無線給電などがあります。プロジェクトの考え方は、メンバーの緒方壽人による[『コンヴィヴィアル・テクノロジー　人間とテクノロジーが共に生きる社会へ』](https://convivial.tech/)（2021）にまとまっています。

プロジェクトから生まれた会社と、当時のメンバーの現在：[Elephantech, Inc.](https://elephantech.com/) / [Prof. Koya Narumi](https://narumi.me/inkjet4dprint) / [Prof. Mitsuhiro Kamezaki](https://sites.google.com/view/mitsuhirokamezaki/) / Prof. Cedric Caremel / [Prof. Hiroaki Murakami](https://sites.google.com/view/hiroaki-murakami/) / [Prof. Ken Takaki](https://www.kentakaki.com/) / [Prof. Takuya Sasatani](https://www.takuyasasatani.com/) / [Prof. Ryo Takahashi](https://www.ryotakahashi.me/)
{{< /about-section >}}

{{< about-section id="join" title="研究室に加わる" >}}
研究に必要なのは「発見」する力と「表現」する力、そして手を動かして「つくる」力です。専門知識は、情熱さえあれば後からついてきます。現実の世界で動く知能をつくるので、電気・電子や情報だけが入口ではありません。材料、機械、デザイン、音響、言語など、どの分野からでも、学部でしっかり学んできた人を歓迎します。

メンバーの個性を尊重し、自分から発信する人には積極的にチャンスを与えます。自分で問いを立てた学生が、国内外の会議や論文誌で発表を重ね、企業の研究者と実用化に向けた共同研究を進めています。研究室の技術から会社が生まれ、製品として世に出た例もあります。

入り方は一つではありません。修士特別口述試験、一般入試、海外からのインターンシップや IME プログラム、博士研究員——どの経路で入っても、メンタリングも、プロジェクトへの参加機会も、RA への応募機会も、同じように開かれています。自分のアイディアを咲かせ、実らせる機会を求める人を歓迎します。
{{< /about-section >}}

{{< about-section id="admissions" title="電気系工学専攻修士特別口述試験への出願を検討している皆様へ" >}}
修士特別口述試験への出願を検討している学生の皆さんに、研究室としての方針と期待をお伝えします。特別口述試験の出願者は、出願に先立って研究指導を希望する教員に事前に連絡をとり、研究計画について相談することが推奨されています。私たちの研究室では、次のような学生を歓迎します。

1.  トップレベルの研究環境で、主体的かつ意欲的に研究に取り組もうとする学生を求めています。特に、博士課程への進学を将来的な選択肢の一つとして考えている学生を歓迎します。その旨を志望理由書に明確に記載してください。
2.  私たちの研究内容を十分に理解した上で、センシングとAI技術を融合させたEmbodied AIやPhysical AI分野において学術的な貢献を目指す学生を歓迎します。ただし、出願時に卒業論文などで取り組んでいる研究テーマが必ずしもこれらの分野と完全に一致している必要はありません。修士課程において新たな研究テーマに挑戦する意欲を特に重視します。
3.  電気電子・情報・通信系に限らず、多様な分野でしっかりとした学部教育を受けた学生を歓迎します。電気電子・情報・通信以外の分野から出願する場合は、これまでどのような学術的基礎を培ってきたかを具体的かつ明確にアピールしてください。

修士特別口述試験の枠は非常に限られています。そのため、選考に通過できなかった場合でも落胆することなく、ぜひ一般入試での入学を目指してください。修士特別口述試験、一般入試のいずれで入学しても、その後の研究室での取り扱いに差は全くありません。全ての学生に対し、平等なメンタリングを提供し、オープンな研究プロジェクトへの参加機会やRAへの応募機会を保証しています。 皆さんの積極的な出願を心よりお待ちしています。
